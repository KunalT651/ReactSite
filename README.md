# Kunal Thakare - Portfolio Website (React)

This React site reads data from the Assignment 1 backend API (Express) and displays experiences, skills, and projects. It includes a contact page with info and a simple form.

## Requirements
- Node.js LTS installed
- Assignment 1 backend API running (local) with CORS enabled

## Configuration
Create a `.env` file at the project root and set the API base URL:
```
REACT_APP_API_URL=http://localhost:4000/api
```

## Scripts
- Development: `npm start`
- Build: `npm run build`
